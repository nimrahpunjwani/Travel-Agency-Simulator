# Travel Agency Simulator

## Description

Travel agencies often face challenges with **manual management of bookings, agents, customer data, and travel packages**, leading to inefficiency and errors.

**Travel Agency Simulator** is a **Java-based application** that solves these problems using **Data Structures** and **DBMS** concepts. The application allows administrators to efficiently manage agents, customers, bookings, dynamically create travel packages, and simulate online payment functionality.

---

## Features

* **Admin login and authentication**
* **Agent management:** Add, edit, delete, and view agents
* **Customer management:** Add, edit, delete, and view customers
* **Booking management:** Efficiently handle customer bookings
* **Travel package creation:** Dynamically create and manage travel packages
* **Online payment simulation:** Simulate payment process for bookings

---

## Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Data Structures:** Arrays, lists, etc.
* **Database Management System (DBMS):** Storing records efficiently
* **JavaFX:** GUI implementation for interactive user experience

## Installation & Running Locally

Follow these steps to run the **Travel Agency Simulator** on your local machine:

1. **Clone the repository:**

```bash
git clone https://github.com/nimrahpunjwani/travel-agency-simulator.git
```

2. **Navigate to the project directory:**

```bash
cd travel-agency-simulator
```

3. **Open the project in your preferred Java IDE** (e.g., IntelliJ IDEA, Eclipse, NetBeans).

4. **Ensure you have Java JDK 17 or higher installed.**

5. **Build and run the project:**

* If using an IDE, run the `TVASgui` class.
