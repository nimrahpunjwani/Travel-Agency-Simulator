# Travel Agency Simulator

## Description
Travel agencies often struggle with manual management of bookings, agents, customer data, and travel packages, leading to inefficiency and errors. The Travel Agency Simulator is a Java-based application that solves these problems using Data Structures and DBMS concepts. It allows administrators to manage agents, customers, bookings, dynamically create travel packages, and simulate online payment functionality.

## Features
- Admin login and authentication  
- Add, edit, delete, and view agents  
- Add, edit, delete, and view customers  
- Manage bookings efficiently  
- Dynamically create travel packages  
- Online payment simulation for bookings  

## Technologies Used
- Java  
- Object-Oriented Programming (OOP)  
- Data Structures (arrays, lists, etc.)  
- Database Management System (DBMS) for storing records  
- JavaFX for implemented GUI
